# cleared-media

Public images, Reels and documents for **Cleared** posts on Instagram ([@areyoucleared](https://www.instagram.com/areyoucleared/)), X ([@areyoucleared_](https://x.com/areyoucleared_)) and [LinkedIn](https://www.linkedin.com/company/areyoucleared/).

Everything here is generated and published automatically. Nothing is hand-made, and this is not a code repository.

| Path | Contents |
|---|---|
| `YYYY-MM-DD/` | One folder per week (its Monday) |
| `YYYY-MM-DD/<post>/` | That post's slides (`1.png`, `2.png` ...), `reel.mp4` or `doc.pdf` |

*It's a dating app. Everyone here is cleared.*
